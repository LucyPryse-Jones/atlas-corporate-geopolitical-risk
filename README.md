# Atlas: Corporate Geopolitical Exposure & Transaction Risk Monitor

## Overview

Atlas is a Python-based case-study tool that assesses how geopolitical and policy risks could affect a company’s operations, supply chain, valuation and suitability as an acquisition target.

The project is framed around a hypothetical European acquisition of a battery-materials supplier. It considers exposure across the Democratic Republic of Congo, China, Chile and the European Union.

## Decision question

Should a hypothetical European industrial buyer proceed with the acquisition, and which geopolitical risks should it diligence, price and mitigate?

## Planned outputs

- A country and risk-category heatmap
- An exposure-weighted risk scorecard
- Three geopolitical scenarios and estimated EBITDA / valuation effects
- A due-diligence workplan and mitigation recommendations
- An investment-committee-style memo

## Tools

- Python
- pandas
- Plotly
- pytest
- Streamlit, planned for a later version

## Important disclaimer

This is an educational case study using illustrative assumptions and public contextual sources. It does not represent a real company’s supply chain or financial position, and it is not investment, legal or transaction advice.
